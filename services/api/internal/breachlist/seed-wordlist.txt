# breachlist bootstrap seed wordlist
#
# This is a BOOTSTRAP SEED corpus, not the full HIBP top-1M. It is a curated
# list of the most-prevalent breached passwords — all public knowledge,
# appearing at the top of every published breach-frequency list (RockYou,
# HIBP Pwned Passwords prevalence order, SecLists "10-million-password-list",
# NCSC "top 100k", etc.). It exists to wire up and test the full breach-screen
# seam end-to-end while the real 20 MB HIBP ordered corpus is a documented
# follow-up swap (see scripts/gen-breachlist.sh + docs/breachlist-provenance.md).
#
# Format: one plaintext password per line. Blank lines and lines beginning with
# '#' are ignored. A single trailing CR (CRLF endings) is stripped so a
# CRLF-saved file still hashes the intended bytes; other whitespace is kept.
# The generator SHA-1s the exact remaining bytes — keep entries as the literal
# password.
#
# To swap in the real HIBP top-1M: see scripts/gen-breachlist.sh -hibp mode.
