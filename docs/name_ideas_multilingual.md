# Name Ideas — Other Languages

## Arabic (عربي)
- **Khayyal (خيال)** — phantom / ghost / illusion
- **Zill (ظل)** — shadow
- **Wahn** — mirage (also German, double meaning)
- **Talaf (تلف)** — waste / damage
- **Samt (صمت)** — silence / idle stillness
- **Faqd (فقد)** — loss

## Japanese (日本語)
- **Muda (無駄)** — waste (famous from Toyota Lean / Kaizen — deeply resonant in DevOps culture)
- **Kage (影)** — shadow
- **Yūrei (幽霊)** — ghost / spirit
- **Kumo (雲)** — cloud (literal, poetic)
- **Ochi (落ち)** — fall / drop (as in costs dropping)
- **Nuru** — lurk / linger

## Latin
- **Umbra** — shadow (also used in astronomy, strong word)
- **Vacuus** — empty / idle
- **Ignis** — fire / burn
- **Vanus** — hollow / wasted / in vain
- **Relictus** — abandoned / left behind
- **Inanis** — empty / worthless

## German (Deutsch)
- **Leerlauf** — idle run / zero-load operation (engineering term, very precise)
- **Schatten** — shadow
- **Verlust** — loss / waste
- **Reste** — remnants / leftovers
- **Geist** — ghost / spirit (also: Zeitgeist)
- **Treibgut** — driftwood / debris — things drifting at cost

## French
- **Fantôme** — ghost (strong, elegant)
- **Brume** — mist / haze — things half-visible, half-forgotten
- **Résidu** — residue / leftover
- **Déchet** — waste (too negative in connotation)
- **Veille** — standby / idle state (exact technical meaning)

## Spanish
- **Fantasma** — ghost
- **Sombra** — shadow
- **Merma** — shrinkage / loss / waste (used in finance/logistics)
- **Rastro** — trace / leftover trail
- **Olvido** — forgotten / oblivion — "the forgotten resources"

## Hindi / Sanskrit
- **Maya (माया)** — illusion / something that appears real but isn't
- **Chaya (छाया)** — shadow
- **Kshaya (क्षय)** — decay / waste / loss (used in accounting contexts)
- **Nashta (नष्ट)** — destroyed / wasted

## Finnish
- **Haamu** — ghost (short, punchy, unique in the SaaS space)
- **Jäänne** — remnant / leftover
- **Hukka** — waste / loss ("hukkaan" = gone to waste)

## Swahili
- **Kivuli** — shadow
- **Bure** — free / wasted / in vain ("bure kabisa" = completely wasted)
- **Mzigo** — burden / load

## Shortlist — Best for a SaaS Brand

| Name | Language | Meaning | Why it works |
|------|----------|---------|--------------|
| **Muda** | Japanese | Waste | Lean/DevOps culture knows this word — instant credibility |
| **Umbra** | Latin | Shadow | Clean, short, professional, no negative connotations |
| **Haamu** | Finnish | Ghost | Unique, short, zero brand conflicts, memorable |
| **Maya** | Sanskrit | Illusion | Universal recognition, elegant, "costs that feel unreal" |
| **Veille** | French | Standby/Idle | Exact technical meaning, sophisticated |
| **Khayyal** | Arabic | Phantom/Illusion | Strong meaning, founder's native language — authentic story |
| **Geist** | German | Ghost/Spirit | Familiar to Western audiences (Zeitgeist), registered in Germany |

---

## Top 3 Recommendation

1. **Muda** — engineers who know Lean will immediately get it. Strong narrative: "cloud waste is muda."
2. **Umbra** — the most brandable. Clean, short, Latin gravitas, works in every language.
3. **Khayyal** — most authentic given the founder's background. A great press story: "named after the Arabic word for phantom."
